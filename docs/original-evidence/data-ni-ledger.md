## What this settles

- **The scan found item fields the map and the editor lacked.** The original reads the worn-equipment modifiers (strength, quickness, movement, psi resistance, psi
  points and hands at bytes 0, 2, 5, 6, 7 and 8), the shield cost (word 92 and byte 80), the energy a weapon needs (word 146), the target mode and animation of the
  panel (words 56 and 58), the starting modifiers of a new copy (bytes 78, 83, 84 and 86) and the kind of equipment an upgrade must match (byte 87). `canuse` reads
  an eligibility block: the traits a race must not or must have (104 and 112, nine bits), the Psi schools that must not or may use it (106, seven bits; 114), the one
  race (108) and MOS (110) allowed, and a table of 58 ability bits at 128. The editor now lists all of them; bytes 116 to 127 and the rest are not read.
- **Words 42 to 50 serve several readers.** For worn equipment, words 46 and 48 are the two attributes the item changes and word 50 the amount, which can be negative
  (the editor allowed only 0 and above for word 50, which would have stopped an item that lowers an attribute). For a melee weapon with effect -10 they are the condition slot,
  the saving throw or percent, and the amount. For a class 23 item word 50 is the continuation story.
- **Item sounds take any word.** `sound` takes the absolute value as the `snd ` resource number, plays only when the resource loads, and plays to the end first when
  the value is below 1. The same routine serves monster and attack sounds, so those accept any word too.
- **The icon takes any word**: zero draws nothing and a missing icon resource is skipped.
- **The price** is read only by `itemcost` and `moveicon`, which makes it positive; the editor accepts any value. No cursed-item flag was found in the record.
- **Class** is read through its absolute value in most routines, stored in a byte, and compared signed in some (2, 20, 26, 27); the editor allows -255 to 255.
- **Required level, shield chance and attack count** are plain word reads, compared, copied into an instance or counted down, with no branch on range; the editor allows
  the whole word. The shield chance is capped at 95 when it is rolled.
- The map's own gaps: `condition_feedback_index` and the eligibility accessors are not rows, and `description_id` (0x66) is edited with the description.
- The second and later bytes of a bit table show as "no map row" because `canuse` reaches them by bit number: it loops over 9 trait bits (two bytes), 7 school bits (one byte) and 58 ability bits (eight bytes).
